# GitMaster: Guía Interactiva de Git & GitHub 🚀

¡Bienvenido a **GitMaster**! Una plataforma web educativa y moderna diseñada para aprender los conceptos fundamentales y avanzados del control de versiones con Git y la colaboración en equipo en GitHub.

## 📖 Descripción del Proyecto
Este proyecto fue desarrollado como parte de un trabajo práctico enfocado en el dominio de Git y GitHub. Incluye:
- Conceptos clave: branches, merges, commits atómicos, pull requests y resolución de conflictos.
- Comandos esenciales explicados paso a paso con ejemplos prácticos.
- Interfaz gráfica web responsiva, accesible y semántica construida con HTML5 y CSS3 moderno.
- Flujo de trabajo colaborativo simulando buenas prácticas profesionales de la industria (GitFlow).

---

## 📄 Páginas del Sitio
- **`index.html`**: Página principal con la guía interactiva de conceptos, comandos esenciales y flujo de trabajo en Git & GitHub.
- **`contacto.html`**: Segunda página vinculada con la información del equipo (Tiziano Cárdenas y Agustín Albornoz) y un formulario de contacto.
- **`estilos.css`**: Hoja de estilos compartida para mantener una interfaz moderna y responsiva en todo el sitio.

---

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Marcado semántico y estructurado.
- **CSS3:** Variables CSS, Flexbox, CSS Grid y diseño responsivo adaptado a dispositivos móviles y de escritorio.
- **Git & GitHub:** Control de versiones distribuido y flujo de trabajo en ramas.

## 🚀 Instrucciones para Ejecución Local

Para visualizar y probar este proyecto en tu entorno local, sigue estos pasos:

### 1. Clonar el repositorio
Abre una terminal o consola de comandos y ejecuta:
```bash
git clone https://github.com/Cardenastiziano/Cardenas-Albornoz-Github-Git.git
```

### 2. Acceder al directorio del proyecto
```bash
cd Cardenas-Albornoz-Github-Git
```

### 3. Abrir la aplicación
No se requieren dependencias externas ni servidores backend. Puedes abrir la aplicación de las siguientes formas:

- **Directamente en tu navegador:**
  Haz doble clic en el archivo `index.html` o ábrelo desde tu explorador de archivos con tu navegador web preferido (Chrome, Firefox, Edge, etc.).

- **Con Live Server (Visual Studio Code):**
  Si utilizas VS Code, instala la extensión *Live Server*, haz clic derecho sobre `index.html` y selecciona **"Open with Live Server"**.

- **Con un servidor local de Python:**
  ```bash
  python -m http.server 8000
  ```
  Luego ingresa a `http://localhost:8000` en tu navegador.
