Comandos Esenciales en Terminal

Las instrucciones diarias de todo desarrollador profesional

Clonación inicial git clone <url-del-repositorio>

Descarga un proyecto remoto con todo su historial de cambios.

Crear y cambiar de rama git switch -c feature/nombre-tarea

Crea una rama limpia aislada para desarrollar una nueva funcionalidad.

Confirmar cambios atómicos git commit -m "feat: descripción clara"

Guarda una instantánea de los cambios agregados con git add.

Fusionar trabajo a main git merge feature/nombre-tarea

Integra las mejoras verificadas de la rama de trabajo hacia la rama principal.
